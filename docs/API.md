# API Reference — allah-names-py

## Functions
- `get_all_names()`: Returns list of all 99 AllahName objects.
- `get_by_number(number)`: Look up by number 1 to 99.
- `get_random_name()`: Random Name of the Day.
- `search_names(query)`: Multi-lingual search across Arabic, English meaning, and transliteration.
